# Banking Analytics Project

## Project Overview
This project focuses on analyzing banking data to generate meaningful business insights through data analysis and visualization. It covers two major areas: Bank Loan Analysis and Debit & Credit Card Analysis.

The project uses multiple data analytics tools to explore financial data, analyze key metrics, and present insights through interactive dashboards.

## Project Objectives
- Analyze bank loan performance and funding.
- Understand loan distribution and collection metrics.
- Analyze debit and credit card transactions.
- Compare credit and debit transaction amounts.
- Identify important financial trends and patterns.
- Present business insights through interactive dashboards.

## Tools & Technologies

- **Microsoft Excel:** Data analysis and dashboard creation.
- **SQL:** Data querying, aggregation, and analysis.
- **Tableau:** Interactive dashboard development and visualization.
- **Power BI:** Data modeling, visualization, and interactive reporting.

## Project Structure

### 1. Excel
Contains the Excel-based banking analytics work and dashboards.

### 2. SQL
Contains SQL queries for:
- Banking Analytics
- Debit & Credit Card Analysis

### 3. Tableau
Contains Tableau dashboards:
- Bank Loan Dashboard
- Debit & Credit Dashboard

### 4. Power BI
Contains Power BI dashboards:
- Bank Loan Dashboard
- Credit & Debit Dashboard

## Key Analysis Areas

**Bank Loan Analysis**
- Total loan amount funded
- Total number of loans
- Loan collection analysis
- Key loan performance metrics

**Debit & Credit Card Analysis**
- Total credit transaction amount
- Total debit transaction amount
- Credit-to-debit ratio
- Transaction analysis

## Conclusion

This project demonstrates the application of data analytics tools to banking datasets. By combining Excel, SQL, Tableau, and Power BI, the project provides a structured approach to analyzing financial information and presenting meaningful business insights.
